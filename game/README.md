# Ржавый Рывок — 2D раннер для ПК

Бесконечный бег с прыжками, скольжением и стрельбой. 4 уровня, на каждом свой фон
и босс. После победы над боссом 4-го уровня игра продолжается кругами
(бесконечный бег, сложность растёт). Герой прокачивается между забегами.

## Запуск

Нужен Python 3.9+ (с python.org, при установке отметьте «Add Python to PATH»).

- **Windows:** дважды кликните `run.bat`. При первом запуске он сам установит pygame.
- **Linux / macOS:** `sh run.sh`

Вручную: `pip install -r requirements.txt`, затем `python main.py`.

## Управление

| Действие | Клавиши |
|---|---|
| Прыжок (второй раз в воздухе — двойной) | Пробел / W / ↑ / ПКМ |
| Скольжение (под балкой и дроном) | S / ↓ (в воздухе — быстрое падение) |
| Огонь (удержание) | X / Z / ЛКМ |
| Пауза | Esc |
| Полноэкранный режим | F11 |
| В меню итогов: заново / дальше | R / Enter |

## Геймплей

- **Бег:** препятствия — ящики (можно расстрелять), шипы, бочки (прыжок), балки
  (скольжение), дроны (скольжение, расстреливаются). Лом собирается и даёт опыт.
- **Уровни:** по дистанции (900–1500 м) открывается босс. Перед боем — предупреждение.
- **Бой:** босс атакует по сценариям (низкие снаряды — прыгать, высокие — скользить).
  Стреляйте по боссу, пока он не упадёт.
- **Прокачка:** за опыт герой получает уровни, за каждый уровень — очко навыков.
  Навыки (до 5 рангов): Броня (+HP), Плазмоган (+урон), Перезарядка, Магнит, Сборщик (+опыт).
- **Сохранение:** `save.json` рядом с `main.py` (прогресс, открытые уровни, навыки).

## Арт

Игра использует картинки из `game/assets/`:
`bg_lvl1–4.jpg`, `boss_lvl1–4.png`, `hero_run.png`, `hero_jump.png`.
Если файла нет, рисуется временная графика, поэтому игра запускается всегда.

Чтобы подключить свои картинки, положите исходники в одну папку (например `~/uploads`,
имена как выше, любые форматы png/jpg) и выполните:

```
python tools/prepare_assets.py путь/к/папке
```

Скрипт сделает фоны 1280×720 и уберёт белый фон у спрайтов. Требуется Pillow.

## Одиночный файл

Вся игра (код и арт) собирается в один файл `rust_rush.py` в корне репозитория:

```
python tools/build_single_file.py
```

Для запуска нужен только Python и pygame (`pip install pygame`), остальные файлы не нужны.
Сохранение `save.json` создаётся рядом с файлом. Если в `game/assets/` есть картинки,
они вшиваются в файл, поэтому пересборка после подключения арта обязательна.

## Готовый exe для Windows

Файл `RustRush.exe` собирается автоматически на GitHub (workflow «Build Windows exe»
при каждом пуше в ветку). Скачать: вкладка **Actions** репозитория → последний успешный
запуск → раздел **Artifacts** → `RustRush-windows`. Python для запуска не нужен.
`save.json` создаётся рядом с exe. Сборка сама запускает тесты и проверяет,
что exe не падает при старте.

## Тесты

```
python -m unittest discover -s game/tests -v
```

Тесты без окна: проходят все 4 уровня с боссами, все атаки, сохранение и меню.

## Структура

```
game/
  main.py        точка входа, переходы между экранами
  config.py      экран, физика, уровни, навыки (настройка баланса здесь)
  play.py        игровая сцена: бег, босс, HUD
  entities.py    герой, препятствия, снаряды, боссы
  scenes.py      главное меню, выбор уровня, прокачка, итоги
  ui.py          общие элементы интерфейса
  save.py        сохранение прогресса
  audio.py       звуки (генерируются кодом)
  assets.py      загрузка арта и временная графика
  assets/        арт (см. выше)
  tests/         автотесты
tools/prepare_assets.py   подготовка арта
```
